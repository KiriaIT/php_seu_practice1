# php_seu_practice1 — შეხვედრა 1, სავარჯიშოები

PHP ვებ-ფორმები და მათი დამუშავება `$_GET` და `$_POST` მეთოდებით.

## სტრუქტურა

```
index.php            მთავარი გვერდი — ბმულები ყველა დავალებაზე
assets/style.css     საერთო სტილები
task1/fixed.php      დავალება 1 (ა) — სახელფასო უწყისი, გადასახადი ფიქსირებულია: 20%  ($_GET)
task1/custom.php     დავალება 1 (ბ) — სახელფასო უწყისი, გადასახადის % ირჩევს მომხმარებელი ($_GET)
task2/grades.php     დავალება 2 — ნიშნების უწყისი ($_POST)
task3/quiz.php       დავალება 3 — სტუდენტის შემოწმების ტესტი ($_POST)
```

## გაშვება

საჭიროა PHP 7.4 ან უფრო ახალი ვერსია.

```bash
php -S localhost:8000
```

შემდეგ ბრაუზერში გახსენით: <http://localhost:8000>

XAMPP-ის შემთხვევაში პროექტის საქაღალდე მოათავსეთ `htdocs`-ში და გახსენით `http://localhost/php_seu_practice1/`.

## დავალება 1 — სახელფასო უწყისი (`$_GET`)

ველები: სახელი, გვარი, დაკავებული თანამდებობა, ხელფასის რაოდენობა (ყველა სავალდებულოა).

- **(ა) `task1/fixed.php`** — საშემოსავლო გადასახადი ფიქსირებულია და შეადგენს 20%-ს.
- **(ბ) `task1/custom.php`** — საშემოსავლო გადასახადის პროცენტს მომხმარებელი ირჩევს ჩამონათვალიდან (5%, 10%, 15%, 20%, 25%, 30%).

გამოთვლა:

```
საშემოსავლო გადასახადი = ხელფასი × განაკვეთი / 100
ხელზე ასაღები ხელფასი   = ხელფასი − საშემოსავლო გადასახადი
```

მაგალითი (20%): ხელფასი 1500 ₾ → გადასახადი 300 ₾ → ხელზე ასაღები 1200 ₾.

შედეგი გამოდის HTML ცხრილში (`<table>`): სახელი, გვარი, თანამდებობა, დარიცხული ხელფასი, განაკვეთი, საშემოსავლო გადასახადი, ხელზე ასაღები ხელფასი.

## დავალება 2 — ნიშნების უწყისი (`$_POST`)

ველები: სტუდენტის სახელი და გვარი, კურსი, სემესტრი, სასწავლო კურსი, მიღებული ქულა (0–100), ლექტორის სახელი და გვარი, დეკანის სახელი და გვარი (ყველა სავალდებულოა).

| შეფასება | განმარტება         | ქულა    |
|----------|--------------------|---------|
| A        | ფრიადი             | 91–100  |
| B        | ძალიან კარგი       | 81–90   |
| C        | კარგი              | 71–80   |
| D        | დამაკმაყოფილებელი | 61–70   |
| E        | საკმარისი          | 51–60   |
| FX       | ვერ ჩააბარა        | 41–50   |
| F        | ჩაიჭრა             | 0–40    |

FX — სტუდენტს უფლება აქვს გავიდეს დამატებით გამოცდაზე; F — საგანი ახლიდან აქვს შესასწავლი.

შედეგი გამოდის HTML ცხრილში: სტუდენტის მონაცემები, კურსი, სემესტრი, სასწავლო კურსი, ქულა, შეფასება და მისი განმარტება, ლექტორი და დეკანი. დამატებით ნაჩვენებია შეფასების სკალა, სადაც მიღებული შეფასება გამოყოფილია.

## დავალება 3 — სტუდენტის შემოწმების ტესტი (`$_POST`)

სულ 5 შეკითხვა:

- 3 **ტესტური** — 4 სავარაუდო პასუხი, სწორია მხოლოდ ერთი (`radio`);
- 2 **ღია** — პასუხს სტუდენტი წერს ტექსტურ ველში (`input`).

გაგზავნის შემდეგ პროგრამა ადარებს პასუხებს სწორ პასუხებს და ბეჭდავს შედეგს, მაგ.: **„სწორი პასუხების რაოდენობა: 3/5“**, ასევე თითოეული შეკითხვის დეტალურ შემოწმებას ცხრილში.

ღია პასუხის შედარებისას რეგისტრი, ზედმეტი ჰარები და ბოლოში მდგარი `()`/`;` მხედველობაში არ მიიღება (მაგ. `count`, `COUNT`, `count()` — ყველა სწორია).

## უსაფრთხოება და ვალიდაცია

- ყველა სავალდებულო ველი მოწმდება სერვერზეც (არა მხოლოდ HTML `required` ატრიბუტით);
- რიცხვითი ველები მოწმდება `filter_var`-ით, ჩამონათვალის მნიშვნელობები — დასაშვებ სიასთან შედარებით;
- მომხმარებლის მიერ შეყვანილი ყველა მონაცემი გამოდის `htmlspecialchars`-ით (XSS-ისგან დაცვა);
- ტესტის სწორი პასუხები ინახება მხოლოდ სერვერზე და HTML-ში არ ჩანს.
